# 小莫划船机 App · 设计规范

> 版本 v0.3 · 2026-05-17 · 配套高保真原型 `prototype/index.html`
> 规范从原型源码抽取,Flutter 实现以此为准。所有 token 命名沿用原型 CSS 变量。

---

## 1. 设备与画布

- 目标机:Xiaomi 17 Pro,6.3″,物理 1220×2656(≈19.6:9,比例 2.18),DPR≈3。
- 设计基准:**逻辑宽 412**(等效 DPR≈3 的 CSS 像素),竖屏,App **全屏铺满**(无设备外框、无安全留白以外的边距)。
- 响应式:宽度 `min(412, 100vw)` 居中,高度 100vh;内容区滚动,底部 Tab 固定。

## 3. 字体与字号

- 字体:系统(`-apple-system, PingFang SC, Microsoft YaHei, Segoe UI, Roboto`)。
- Hero 大数字 54 / 仪表盘 tile 数值 30 / 详情距离 46 / 倒计时 128;标题 18–21;正文 13–15;次要 11–12.5。
- 字重:数值/标题 800,强调 700,正文 600,弱 500。

## 4. 间距 · 圆角 · 阴影

- 间距栅格:4 / 8 / 11 / 13 / 16 / 20(px),卡片间距 13,屏边距 16。
- 圆角:卡片 16–20,按钮 15–18,tile 16,chip 11–12,徽章/胶囊 999。
- 阴影:`--shadow = 0 6px 22px rgba(20,32,64,.07)`;主按钮 `0 8px 18px rgba(47,107,255,.28)`。

## 6. 图标

- 统一线性图标,`viewBox 0 0 24 24`,描边 2、`stroke-linecap/linejoin=round`;面性仅用于心形(心率/卡路里)。
- 语义正确(例:训练目标=旗帜,定距=尺子,自由划=划船,定时=表盘,定卡=心形,间歇=波形,目标配速=靶心)。

## 7. 动效

- 页面切换:`.screen.active` 0.2s 纯淡入(opacity),**不得用 transform 位移/缩放**(避免点击/审查浮层错位)。
- 自动连接:脉冲光环 `pl` 2.1s 循环。
- 倒计时:128px 数字 3→2→1→GO,每步 ~0.8s 自动流转。
- 按压态:按钮 `:active` 下沉 1px + 轻微变暗;列表/chip/Tab `:active` 浅灰底反馈。

## 8. 布局硬性约束(防点击错位)

- 根容器全屏铺满视口,**全局零 transform、零页面级缩放、无文档溢出**(文档尺寸 == 视口,1:1)。
- 预览/真机均按手机视口呈现;切勿用 transform scale 适配(浏览器点击正确但外部审查/点击浮层不跟随 transform → 视觉与命中错位)。
